## Данные

`data/breast_cancer.csv` — встроенный датасет scikit-learn. Цель: `malignant=1` (злокачественная опухоль). **Стоимость ошибок не дана преподавателем**: для учебной демонстрации принято `FN=5`, `FP=1`; порог выбирается на validation. Согласуйте цену с преподавателем перед сдачей. Медицинские выводы из этой модели делать нельзя.

## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr05.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Выполнено (вариант B)

- LogisticRegression + `predict_proba`.
- ROC, PR, ROC-AUC и AP; матрицы ошибок при двух порогах.
- Выбор порога по стоимости ошибок **на validation**, не на test.
- Precision, Recall, F1, Accuracy и экономический условный cost в сравнительной таблице.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr05.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.

## Вывод

В notebook находятся пояснения, интерпретация наблюдений и ограничения. Значения метрик рассчитываются программно и выводятся на основе фактических данных, а не вписываются заранее.
