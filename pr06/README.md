# Практическая работа №6 — уровень B

**Дисциплина:** Машинное обучение  
**Тема:** Классификация текстов  
**ФИО:** Халилов Нурсейит

## Данные

`data/reviews.csv` — авторский **синтетический** корпус коротких русскоязычных отзывов с метками 0/1 и нарочно встречающимися неоднозначными фразами. Датасет преподавателя не предоставлен; для сдачи на нём потребуется заменить файл и проверить результат.

## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr06.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Выполнено (вариант B)

- Очистка нижнего регистра, цифр, пунктуации и стоп-слов; отрицания сохранены.
- Токенизация и TF-IDF (`min_df`, `max_df`, биграммы), логистическая регрессия.
- Split до обучения TF-IDF, метрики Accuracy/F1 и матрица ошибок.
- Анализ 5 фактических ошибок тестовой выборки, сохранён `reports/five_errors.csv`.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr06.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.

## Вывод

В notebook находятся пояснения, интерпретация наблюдений и ограничения. Значения метрик рассчитываются программно и выводятся на основе фактических данных, а не вписываются заранее.
