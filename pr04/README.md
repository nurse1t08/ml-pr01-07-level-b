# Практическая работа №4 — уровень B

**Дисциплина:** Машинное обучение  
**Тема:** Регрессионная модель  
**ФИО:** Халилов Нурсейит

## Данные

`data/diabetes.csv` — встроенный набор `load_diabetes` из scikit-learn, 442 объекта, 10 числовых признаков, непрерывный `progression_score`. В ПР-4 преподаватель датасет не предоставляет: выбран публично известный набор для воспроизводимости.

## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr04.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Выполнено (вариант B)

- Обучение базовой линейной регрессии на всех числовых признаках.
- Корреляционная матрица по train и автоматическое исключение сильнокоррелирующих признаков (|r| >= 0.80).
- Сравнение MAE, RMSE, R²; графики остатков.
- Обоснование выбора и таблица метрик `reports/metrics.csv`.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr04.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.

## Вывод

В notebook находятся пояснения, интерпретация наблюдений и ограничения. Значения метрик рассчитываются программно и выводятся на основе фактических данных, а не вписываются заранее.
