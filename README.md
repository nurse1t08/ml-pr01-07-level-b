## Как запустить практическую

Например, для практической №1 на macOS/Linux:

```bash
cd pr01
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

Для следующей практики перейди в её папку и выполни те же команды. На Windows активация: `.venv\Scripts\activate`.

- **`notebooks/prNN.ipynb`** — готовый ноутбук с кодом и сохранёнными выводами.
- **`data/`** — CSV с исходными учебными данными.
- **`figures/`** — сохранённые графики (если требуются).
- **`reports/`** — таблицы результатов (где применимо).
- **`README.md` в каждой папке** — цель, использованные данные, запуск, выводы и оговорки.

## Важно о данных

Некоторые данные и условия **не были приложены к методичке**. Для ПР-2/3 использован синтетический датасет с пропусками и выбросами, для ПР-6 — синтетические отзывы. В ПР-5 демонстрационная стоимость ошибок: FP = 1, FN = 5. В ПР-7 использован датасет из ПР-5 (требует согласования с преподавателем). Для ПР-1 вместо `tips` использован допускаемый аналог `iris`.

Это воспроизводимые учебные решения уровня B, но при требовании конкретных данных преподавателя их нужно подставить и повторить расчёты.
