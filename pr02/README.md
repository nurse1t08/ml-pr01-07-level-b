## Данные

`data/dirty_employees.csv` — синтетические учебные данные, созданные для демонстрации EDA. **Файл с дефектами от преподавателя не предоставлен**: для строгого соответствия заданию нужно заменить его данными преподавателя и при необходимости адаптировать имена столбцов.

## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr02.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr02.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.
