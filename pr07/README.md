# Практическая работа №7 — уровень B

**Дисциплина:** Машинное обучение  
**Тема:** Случайный лес

## Данные

`data/breast_cancer.csv` — тот же набор, что в ПР-5. Преподаватель должен согласовать выбор датасета предыдущих практик; здесь он использован для воспроизводимости.

## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr07.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Выполнено (вариант B)

- DecisionTree и RandomForest с параметрами по умолчанию на одном train/test.
- `GridSearchCV` на train с `n_estimators`, `max_depth`, `min_samples_leaf`.
- Таблица Accuracy/F1/ROC-AUC, встроенная важность с графиком.
- Эксперимент удаления 5 и 10 слабых признаков, сравнение по CV без использования test при выборе числа признаков.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr07.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.

## Вывод

В notebook находятся пояснения, интерпретация наблюдений и ограничения. Значения метрик рассчитываются программно и выводятся на основе фактических данных, а не вписываются заранее.
