## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr03.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Выполнено (вариант B)

- Явная таблица стратегий заполнения по каждому признаку.
- `ColumnTransformer` с `SimpleImputer`, `StandardScaler`, `OneHotEncoder`.
- Split 80/20 выполнен до расчёта обучаемых статистик.
- Показаны размерности, имена признаков и отсутствие NaN.
- Сохранён `reports/shapes.csv`.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr03.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.

## Вывод

В notebook находятся пояснения, интерпретация наблюдений и ограничения. Значения метрик рассчитываются программно и выводятся на основе фактических данных, а не вписываются заранее.
