## Данные

Iris (`data/iris.csv`) из встроенного набора scikit-learn: 150 цветков, 4 числовых признака и `species` (категория). По методичке допускается табличный аналог `tips`; если преподаватель требует именно `tips`, данные нужно заменить.

## Запуск

Рекомендуется Python 3.11+. На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

На Windows окружение активируется через `.venv\Scripts\activate`; затем те же `pip` и `python run.py`. Никаких абсолютных путей к домашнему каталогу нет.

После запуска выполненный notebook сохраняет результаты непосредственно в `notebooks/pr01.ipynb`, а графики — в `figures/`. Поскольку результаты сохранены, преподаватель может увидеть вывод без повторного запуска.

## Структура

- `data/` — исходные учебные данные CSV;
- `notebooks/pr01.ipynb` — код, графики, выводы;
- `figures/` — графики для отчёта;
- `reports/` — таблицы измерений / выводы;
- `run.py`, `run.sh` — запуск notebook одной командой.
